# 协作白板 · Pinboard

一个可自托管的实时协作白板。便签、图片和笔迹可以被「图钉」固定在画板上；图钉侧栏汇总所有重点；支持跟随视角、激光笔、表情回应和三语界面（简体中文 / 繁體中文 / English）。

前端为 Vite + TypeScript + Canvas，多人协作基于 Yjs CRDT，服务端提供 WebSocket 同步与图片资产存储，全部可在一个 Node 进程和 Docker 中运行。

---

## 功能

- **白板内容**：便签、纯文本文字框、图片、画笔笔迹、带箭头的连线；拖动、缩放、多选框选、复制/粘贴、层级调整。文字框使用透明背景，支持独立字号、文字颜色与自动增高。
- **丰富颜色**：便签、文字和画笔分别提供 12 种预设色与自定义取色器；右键菜单同样支持自定义颜色，便签底色较深时会自动切换为高对比文字。
- **顺滑画笔**：压感笔会随力度改变笔迹粗细，并可在画笔面板自定义压感强度；鼠标笔迹使用圆角连接与低通平滑，不会在直角或曲线处产生突兀折角。提供钢笔、马克笔和荧光笔三种笔刷与悬停笔刷大小预览。
- **橡皮擦**：`R` 切换橡皮，按笔迹擦除，支持连续滑动一次撤销；钉住的笔迹不会被误擦除。
- **清晰的选中反馈**：多选时只显示一个整体选中框；组合内部仅显示组合外框，不再为每个成员绘制重复方框。
- **轻量进入与分享昵称**：打开页面无需填写昵称，自动使用访客身份直接进入；首次点击「邀请」时才设置昵称，随后自动复制链接。昵称保存在当前浏览器，后续分享不再询问。
- **便签富文本**：编辑时通过格式栏对选中行设置字号、加粗、斜体、下划线与删除线，支持左/中/右对齐、无序列表和有序列表，以及一键清除格式；格式随协作实时同步，也会写入导出文件。
- **组合与套索**：框选或使用 `S` 曲线套索沿任意方向圈选内容，`Ctrl+G` 组合。点击组内任意成员会整体选中，可整体移动、复制或取消组合。旧便签会自动迁移到富文本行结构。
- **图钉**：便签、图片、笔迹都可以钉住。钉住后位置/尺寸锁定，但文字仍可编辑；混合选择删除时只删除未钉住内容，钉住项会自动保留。顶部图钉图标再次点击即可解锁。
- **图钉汇总侧栏**：`G` 打开，搜索并定位钉住内容，可直接取消钉住。实时同步所有人的钉住状态。
- **实时协作**：房间链接、真实在线头像、远程光标、断线重连、IndexedDB 本地缓存；离线编辑在重连后自动合并。
- **协作临场感**：点头像跟随队友视角；按住 `L` 使用激光笔；表情菜单可在任意位置通过 `E`、`Alt`+点击或长按空白画布唤出，连续选择会叠加计数（最高 ×99）。
- **操作指引**：左下角为 `?` 指引入口，按 `?` 打开同一份指南；替代了原先常驻的快捷提示，画布更干净。
- **缩略图**：可用缩略图右上角的「隐藏」或 `M` 收起，右下角保留一个恢复按钮；拖动缩略图为低灵敏度相对平移，单击则平滑定位。
- **设置**：双击便签编辑 / 双击空白新建默认关闭，可在「更多 → 设置」中开启；缩略图显隐也保存在本机。
- **字体**：自托管 Inter Variable 覆盖拉丁字符，并按语言选用 Apple / Windows / 开源中文字体回退栈；画布与编辑框使用同一字体栈。
- **图片**：选择、拖入或粘贴图片；客户端压缩、SHA-256 去重、服务端落盘、离线缓存与补传。
- **撤销重做**：`Y.UndoManager`，只撤销自己的操作，支持合并一次拖拽/一段编辑。
- **导入导出**：导出 PNG（含图钉状态与富文本排版）、导出 JSON（图片内嵌、保留格式与分组）、导入 JSON 合并到当前画板。
- **国际化**：自动识别浏览器语言，菜单中可切换三种语言；界面文案、格式工具栏、时间提示、画布空态、确认框全部本地化，并针对较长的英文文案做了响应式处理。

## 快速开始

要求 Node.js 22+（推荐）与 npm。

```bash
npm install
npm run dev
```

- Web：<http://localhost:5173>
- 同步服务：`http://localhost:1234`（由 Vite 代理 `/ws` 与 `/api`）
- 开发环境数据目录：`./data`

打开首页会自动生成房间号并跳转到 `/r/<roomId>`，默认以访客身份直接进入。把地址发给队友即可共同编辑；首次点击「邀请」时会要求设置昵称，保存后自动复制链接。

### 生产运行

生产默认监听 **18016**（可用 `PORT` 覆盖，服务端会自动读取 `.env`）。

```bash
npm run build
npm start
# 等价于
NODE_ENV=production node server-dist/index.cjs
```

生产模式下单进程同时提供静态站点、WebSocket 和图片接口：<http://localhost:18016>。

### Docker

```bash
docker compose up --build -d
```

Docker 映射宿主端口 `18016`，数据保存在 `pinboard-data` 卷中（容器内 `/data`）。如需公网部署，请在前面加 Caddy/Nginx 等反向代理并启用 HTTPS（WebSocket 会自动走 `wss://`）。

示例 Caddyfile：

```caddyfile
board.example.com {
    reverse_proxy 127.0.0.1:18016
}
```

## 环境变量

复制 `.env.example` 为 `.env`（服务端会自动读取），或直接通过 shell / Compose 注入。

| 变量 | 默认值 | 说明 |
|---|---|---|
| `PORT` | 开发 `1234`，生产 `18016` | HTTP 与 WebSocket 监听端口 |
| `HOST` | `0.0.0.0` | 监听地址 |
| `DATA_DIR` | `./data` | 房间快照与图片资源目录 |
| `WEB_DIST` | `./dist` | 静态站点目录 |
| `ALLOWED_ORIGINS` | 空（允许所有） | 逗号分隔的 WebSocket Origin 白名单，公网部署建议设置 |

数据结构：

```
data/
├─ rooms/<roomId>.bin      # Yjs 文档快照（防抖写入 + 最后连接断开时落盘）
└─ assets/<roomId>/        # SHA-256 图片文件与 MIME 元数据
```

备份时直接复制 `data/` 即可；也可以使用菜单中的「导出 JSON」做单画板备份。

## 图钉语义

- 钉住 = 锁定位置与尺寸 + 避免误删除；**不锁定文字编辑和换色**。
- 选中多个内容执行删除时，只删除未钉住的目标，钉住项保持不变；只有全部选中项都钉住时才阻止删除。
- 钉子固定在内容上沿居中，位于 `Shift+P` 快捷键与选中工具栏；图钉汇总侧栏用 `G` 打开。
- 钉住不改变 z 序（需要置顶请使用「移到最前」）。
- 复制/粘贴、复制副本产生的新内容默认**未钉住**，避免复制出不可移动的重叠卡片。
- 多人协作下，钉住是**客户端软锁**：正常操作会在所有端拦截，但并发冲突由 Yjs 合并决定，不构成服务端强一致锁。若 A 钉住的同时 B 已在拖动，最终状态可能同时包含「已钉住」和 B 的新位置。

### 协作实现要点

- 文档根节点：`items: Y.Map<Y.Map>` + `meta: Y.Map`；便签正文为 `Y.Array<Y.Map>` 行块，每行包含 `Y.Text` 与字号、粗体、列表等格式属性；文字框正文是独立 `Y.Text`；笔迹点为 `Y.Array`，同时记录可选压感值、笔刷样式、压感强度与自定义颜色。
- 旧的纯文本便签会在首次编辑时迁移为行块；文字按行增量合并，格式也通过 Yjs 同步。输入法合成期间不应用远端 DOM 重绘，避免拼音候选被打断。
- 组合通过条目上的可选 `groupId` 表示，复制、粘贴和导入时会重新映射组 ID，删除到少于两项时自动解除组合。
- 相机、选中状态、套索路径、昵称、激光和表情属于本地或 Awareness，不写入文档。
- 服务端在最后一个连接关闭时写入完整快照，连接期间每 800ms 防抖保存。
- 图片不入 CRDT：文档只存内容哈希与尺寸，二进制通过 `/api/rooms/:room/assets` 传输，客户端用 IndexedDB 缓存。

```bash
npm test                 # 单元测试（Vitest）
```

```bash

npm run test:e2e:rich      # 格式栏、富文本协作/导出/重载、曲线套索、组合与整体移动
npm run test:e2e:pen       # 钢笔/马克笔/荧光笔、自定义颜色、压感采样、橡皮擦、撤销与钉住保护
npm run test:e2e:text      # 纯文本文字框、字号/颜色、压感强度、扩展色板、多选与组合外框
npm run test:e2e:ux        # 长按/Alt+点击表情、×99 上限、操作指引、缩略图隐藏与拖动灵敏度
```

生产构建冒烟测试（用临时端口 3001 启动服务，避免与 18016 上的正式实例冲突）：

## 安全与限制

- **匿名房间制**：房间链接不可猜测（22 位随机 ID）即可编辑权限，没有账号、角色或密码。不要把敏感内容放在公开链接中。
- 公网部署请启用 HTTPS 并设置 `ALLOWED_ORIGINS`；所有图片经过 MIME/魔数校验，拒绝 SVG，单图上限 15MB。
- 服务端为单节点文件持久化，未实现横向扩展、审计、限流或房间清理策略。
- 图钉为软锁，没有服务端裁决的强一致锁。
- 移动端已使用 Pointer Events，但双指缩放等手势仍属后续迭代。
- 后续可扩展：评论、投票、计时器、画框/演示模式、全文搜索、多画板入口、账号与房间密码。
